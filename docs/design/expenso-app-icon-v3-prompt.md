# Expenso icon concept v3

Generated with the built-in image-generation tool. Modern folded-receipt direction independent of the app accent color. Active app icon unchanged.

## Prompt

Use case: stylized-concept. Asset type: one finished iOS app icon for Expenso, a personal expense tracker. Primary request: a genuinely modern, distinctive sculptural icon, completely unrelated to the app's blue accent and completely unlike a letter monogram. Scene/backdrop: full-bleed matte near-black graphite #191919, subtle warm studio light, no outer rounded square drawn. Subject: one large warm ivory receipt ribbon, thick smooth premium folded paper, sculpted into a confident compact angular zigzag with two broad folds; the front face has only two short deeply embossed horizontal receipt lines and a restrained zigzag-cut lower edge. The folded receipt is an abstract iconic object, not a realistic detailed printed receipt. A small vivid persimmon-orange inner fold is visible as a single precise accent within the ivory ribbon. Style: exceptional contemporary industrial-design render, tactile satin ivory material, architectural folded planes, beautifully controlled soft shadows, clean bold silhouette. Composition: centered, object fills about 66 percent of square, almost front-facing with subtle three-quarter depth, balanced negative space. Strong visual simplicity and contrast at home-screen scale. No text, letters, E, currency symbols, coins, chart, blue, purple, gradients in bright colors, glass bubbles, sparkles, outlines, watermark, border, device mockup or multiple concepts. Full square opaque 1024x1024 artwork, background fills all four corners. Output only the icon.
